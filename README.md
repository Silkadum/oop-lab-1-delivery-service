# Консольный симулятор службы доставки

Практическая работа №1 по дисциплине «Объектно-ориентированное программирование» (СПбГЭТУ «ЛЭТИ», кафедра САПР).

Консольное приложение моделирует работу небольшой службы доставки: оформление заказов из товаров на складе, выбор способа доставки с расчётом стоимости и срока, назначение курьеров и перевод заказов по статусам. Все данные хранятся в оперативной памяти.

## Возможности

- создание заказа и добавление в него товаров со склада;
- изменение корзины заказа (добавление и удаление позиций);
- выбор способа доставки с расчётом стоимости и срока:

  | Способ | Стоимость | Срок | Курьер |
  |---|---|---|---|
  | Стандартная доставка | 300 руб., бесплатно от 5000 руб. | 3–5 дней | нужен |
  | Экспресс-доставка | 500 руб. + 5% от суммы товаров | 1 день | нужен |
  | Самовывоз | бесплатно | готов к выдаче через 2 часа | не нужен |

- назначение свободного курьера;
- смена статуса заказа только по допустимым переходам;
- просмотр, пополнение и уменьшение остатков склада;
- обработка некорректного ввода с понятными сообщениями.

## Запуск

Требуется Python 3.10 или новее. Внешние библиотеки не используются.

```bash
git clone https://github.com/Silkadum/oop-lab-1-delivery-service.git
cd oop-lab-1-delivery-service
python3 main.py
```

## Статусы заказа

```
новый → подтверждён → в пути → выполнен            (курьерская доставка)
новый → подтверждён → готов к выдаче → выполнен    (самовывоз)
```

Отменить заказ можно до отправки: из статусов «новый», «подтверждён» и «готов к выдаче». Товар списывается со склада при подтверждении заказа и возвращается при отмене.

## Структура проекта

```
├── main.py                      # точка входа: склад, курьеры, запуск меню
├── constants.py                 # статусы заказа и тарифы доставки
├── models/
│   ├── customer.py              # Customer — клиент
│   ├── courier.py               # Courier — курьер
│   ├── product.py               # Product — товар на складе
│   ├── order_item.py            # OrderItem — позиция заказа
│   ├── order.py                 # Order — заказ и переходы статусов
│   └── warehouse.py             # Warehouse — склад и остатки
├── delivery/
│   ├── delivery_method.py       # DeliveryMethod — абстрактный способ доставки
│   ├── standard_delivery.py     # StandardDelivery
│   ├── express_delivery.py      # ExpressDelivery
│   └── pickup.py                # Pickup
├── services/
│   └── order_service.py         # OrderService — управление заказами
└── ui/
    └── console_ui.py            # ConsoleUI — меню, ввод и вывод
```

## Принципы ООП

- **Инкапсуляция:** поля объектов приватные и доступны только для чтения через свойства; состояние меняется методами, которые проверяют допустимость операции.
- **Композиция:** заказ содержит клиента, позиции и способ доставки; склад содержит товары.
- **Наследование и полиморфизм:** три способа доставки реализуют абстрактный класс `DeliveryMethod`, поэтому заказу не нужно проверять, какой способ выбран.
- **Разделение ответственности:** бизнес-логика находится в моделях и `OrderService`, ввод и вывод — в `ConsoleUI`.
